## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → PATCH /api/canvas_nodes/:id | Any authenticated participant can change a node's status; untrusted status value + node id cross here |
| client → GET /api/sessions/:id/canvas | Authenticated read of canvas state for a branch |
| LangGraph output → canvas_nodes upsert | AI-emitted ghost/committed ops written to DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Elevation of Privilege | PATCH /canvas_nodes/:id | mitigate | Fetch node.session_id, verify caller is a participant in that session before UPDATE; return 403 otherwise (service client bypasses RLS) |
| T-09-02 | Tampering | PATCH body status | mitigate | Zod `z.enum(['committed','silent'])` — reject any other value with 400 |
| T-09-03 | Information Disclosure | GET /:id/canvas | accept | Committed canvas state is shared with all session participants by design; requireAuth gates unauthenticated access |
| T-09-04 | Denial of Service | dagre layout / ghost accumulation | accept | Node counts bounded by LangGraph invocation budget; pg_cron expires ghosts every 60s |
| T-09-SC | Tampering | pnpm install @dagrejs/dagre | mitigate | slopcheck [OK] in RESEARCH.md audit (official dagre org); no [ASSUMED]/[SUS] packages |
