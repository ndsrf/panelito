<objective>
Wire the client-side canvas reconciliation and panel-routing plumbing: a merge-by-id store action for live broadcasts, a full-replace reconnect fetch on Supabase SUBSCRIBED, a full-replace fetch on branch switch, and server-side canvas_view_mode resolution passed to Workspace. This is everything that keeps the canvas correct across reconnects, branch switches, and multi-turn invocations — before the renderer exists.

Purpose: Without merge semantics, each canvas_update wipes prior nodes (Pitfall 3). Without the reconnect/branch-switch fetches, CANVAS-03 fails. Without server-side view-mode resolution, the panel can't route to the graph (CANVAS-04).

Output: mergeCanvasData store action + test, use-session-channel merge + reconnect handler, workspace branch-switch fetch, page.tsx Blueprint load → canvasViewMode prop.
</objective>
