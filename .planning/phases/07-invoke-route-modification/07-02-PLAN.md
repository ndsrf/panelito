| Boundary | Description |
|----------|-------------|
| client → /invoke route | Untrusted HTTP body (userMessage, branchId, anyoneTyping) crosses here; auth middleware + ownership gate already applied |
| route → graph.astream | Route passes plaintextKey + blueprint + signal into config.configurable |
| graph text → SSE → client | Model tokens stream to all session participants |
| client disconnect → server | AbortSignal must terminate graph to prevent orphaned async work + wasted API cost |
