| speaker string → author_id | ArgNode.speaker is a display name; resolution to a real auth uuid crosses an identity boundary via message_id lookup |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-13-06 | Tampering | Prompt injection via participant content in summarizeParticipant() | mitigate | Mandatory reuse of `escapeUntrustedText()` + `<<<PARTICIPANT_PROFILE_DATA>>>` delimiter framing (WR-06); test asserts a `<<<`-containing position is neutralized. |
| T-13-07 | Spoofing | AI-authored content attributed to a human participant's profile | mitigate | Every messages-derived query filters `role = 'user'`; author_id resolution skips non-user source rows (Pitfall 1). |

| T-13-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase. |
