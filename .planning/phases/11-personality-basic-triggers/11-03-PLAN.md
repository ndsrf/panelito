<objective>
Build ArgGraphBuilderNode: the extraction node that reads recent conversation, calls the extraction tool, substitutes short refs for UUIDs, validates against the real domain schema, and merges the result into `state.argGraph` in PostgresSaver thread state (GRAPH-01, GRAPH-02).

Purpose: The argGraph is the compaction backbone (AI-SPEC 4b.4) — it distills raw conversation into a structured graph so Coach and Analyst prompts scale with argument density, not message count. Finding 2 requires a two-schema split (relaxed tool input vs. strict domain schema) so LLM output actually validates.

| Boundary | Description |
|----------|-------------|
| LLM tool-use output → argGraph state | Untrusted model JSON is validated + UUID-normalized before entering checkpointed state |
| bot thread checkpoint → argGraph | argGraph accumulates only on the bot thread; must not corrupt the human thread |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-07 | Tampering | tool-use extraction input | mitigate | Two-schema split (relaxed tool input, strict ArgGraphSchema after UUID substitution) + `safeParse` drop-on-failure; malformed output never enters state |
| T-11-08 | Denial of Service | retry loop on Zod failure | mitigate | MAX_RETRIES capped at 2; on exhaustion the node returns {} rather than looping; maxTokens 256 bounds generation cost |
| T-11-09 | Tampering | argGraph merge | mitigate | Merge de-duplicates by id and unions with prior state; overwrite reducer receives the fully merged graph so no accumulated content is lost or replaced by a partial |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan |
