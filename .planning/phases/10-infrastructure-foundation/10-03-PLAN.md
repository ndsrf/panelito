## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-07 | Denial of Service | bot-budget checkBotBudget on unknown state | mitigate | Fail-closed: rpc error/no-rows returns allowed=false so bots do not fire when budget state is unknown |
| T-10-08 | Spoofing | silence-gate Presence is_typing | accept | WSL2 fallback assumes not-typing on Presence failure (D-09); accepted risk — worst case a bot fires while someone types, bounded by arbitration lock + budget guard; fallback is logged for observability |
| T-10-09 | Tampering | arbitration winner selection | mitigate | Winner only fires if try_acquire_bot_lock (atomic DB compare-and-set) grants the lock; scoring alone cannot bypass the lock |
| T-10-SC | Tampering | npm/pnpm installs | mitigate | No new packages installed in this plan — all imports are existing workspace deps (@supabase/supabase-js, @panelito/types, vitest); no legitimacy checkpoint required |
