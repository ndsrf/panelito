<objective>
Add Langfuse's native `sessionId` field to the two per-request `CallbackHandler` instantiations so traces are grouped per "room" (called a *session* in this codebase) and can be distinguished across many rooms running in parallel.

Purpose: Langfuse's Sessions feature (https://langfuse.com/docs/observability/features/sessions) groups every trace/generation sharing a `sessionId` under one session view. Today the room id only appears as a `session:<id>` free-text tag, which does NOT populate the Sessions UI. Setting the first-class `sessionId` field unlocks per-room trace grouping and side-by-side comparison of concurrent rooms.

Output: `sessionId` set on both AI trace paths (human-reactive /invoke and proactive silence-gate), verified by test assertions on the CallbackHandler constructor args.
</objective>
